Meta open-sources Astryx, its React design system

Meta released Astryx under the MIT licence in public beta after about eight years of internal use: 150+ accessible components, seven token-based themes, a CLI and a swizzle command that copies a component's source into your repo. It styles with StyleX but accepts Tailwind, CSS modules or plain CSS overrides, which makes it a live reference for theming, ownership and agent-friendly conventions in a large design system.

Google patches an exploited Chrome zero-day

CVE-2026-125350 is a high-severity use-after-free in Chrome's XML component, fixed in Chrome 157.0.8103.50, and Google says an exploit exists in the wild; a second XML flaw, CVE-2026-125346, was fixed in the same release. Update your browsers and check that the Chromium builds behind your visual-regression and end-to-end CI are current.

/* tip of the day */

Use light-dark() to resolve a colour token for both schemes in one declaration instead of duplicating rules in a media query.

:root { color-scheme: light dark; }
.card {
  background: light-dark(#fff, #1c1c21);
  color: light-dark(#111, #f5f5f5);
}
