OpenAI launches ChatGPT Wallet so agents can pay at checkout

On Nov 13 OpenAI started letting its dots agents complete purchases through a saved card, using payment tokens and a Face ID or fingerprint approval, initially for US Pro subscribers. Agents filling in ordinary store checkout forms means your form components, labels and error states are now read by machines as well as people, so accessible, predictable markup pays off twice.

Playwright 1.65 runs tests under Bun and adds a failures reporter

The new release can run the test runner under Bun with bunx --bun playwright test, adds a built-in failures-only reporter and an exclusive test lock, and drops Node.js 20 among its breaking changes. If your component library uses Playwright for visual or interaction tests, check the breaking changes before upgrading, and note that watch mode does not work under Bun yet.

Read source →

Researchers find thousands of Lovable-built apps leaking user data

A study by security firm Crissy Field with Handelsblatt scanned 159,041 Lovable projects and found passport details, payment data and about 200,000 chat messages readable without a login, mostly because database access rules were never set; the story hit the Hacker News front page on Nov 14. AI-generated apps built from your components still need secure defaults, so ship auth-aware patterns and docs, not just pretty UI.
