GitHub blocks pull_request_target by default on 2 December

Public repos lose the trigger unless an Actions event policy allows it, with brownout tests on 9 and 16 Nov (16:00 to 18:00 UTC). Component libraries and token repos with fork-PR workflows should audit now, since this trigger was used in recent compromises of projects like TanStack and Nx.
