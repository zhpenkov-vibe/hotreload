Azure API Management flaw used to steal stored API credentials

Microsoft warned on Nov 23 that a vulnerability in Azure API Management Classic tiers was exploited to steal API credentials stored in the service, and Norwegian authorities tied it to attacks on energy companies. If your design system's docs, token APIs or Storybook backends sit behind APIM Classic, rotate the stored keys now and plan a move off the Classic tier.

Update: OpenRouter drops three AI providers over leaked prompts

Following last week's canary-prompt findings, OpenRouter removed three providers that broke their data-handling policies and exposed sensitive data, and pulled zero-data-retention eligibility from 125 endpoints as a precaution. If your AI tooling routes through a marketplace, pin trusted providers explicitly rather than letting it pick the cheapest one.

Read source →

React Flow 13 is out

The xyflow team shipped React Flow 13, the next major version of the node-based UI library behind many workflow editors, token graphs and design-tool canvases. If your design system wraps React Flow for diagram or pipeline components, read the migration notes before bumping from 12.x.
