Microsoft's agent-framework package was poisoned on PyPI

Wiz found that releases 1.26.1 and 1.26.2 of Microsoft's agent-framework Python package, published on Nov 17 outside the normal release process, carried a credential stealer aimed at Azure, Azure DevOps and GitHub Actions secrets that ran on Python startup even without importing the package. If any of your tooling, docs bots or CI jobs use it, pin 1.26.0, check lockfiles and caches, and rotate CI credentials.

Bell Canada says an 'agentic' attacker stole enterprise data

Bell told BleepingComputer on Nov 20 that an attacker it describes as agentic breached its systems on Nov 17 and took enterprise customer data, and it has not yet identified who was behind it. Machine-speed intrusions are no longer hypothetical, so short-lived tokens and least-privilege access for design and deploy tooling now matter as much as for production.

Roundups report GPT-6.2 and Gemini 4 Neon releases

Weekly AI roundups report that OpenAI released GPT-6.2 Astra and Sol last Tuesday and that Google launched Gemini 4 Neon at $3 per million input tokens with a 1M-token context window, though we have not seen the vendors' own announcements yet. If confirmed, both are new options for code and docs generation in your design system, so check the official model pages before switching.
