Cloudflare open-sources Kitesurf, its browser engine for AI agents

Kitesurf, the agent-first browser Cloudflare launched in August, is now on GitHub under Apache 2.0, built from a Rust headless engine plus Blitz rendering, Firefox's Stylo CSS parser and the Boa JavaScript engine, with no Chromium underneath. As more agents browse with engines like this, components that rely on semantic HTML and standard CSS will hold up far better than ones that assume Chrome.

Siri can now read the whole page in Safari

The second iOS 27.3 beta adds an Ask About Page feature that lets Siri read the full content of a webpage in Safari, not just what is visible on screen. Assistants reading your entire DOM make headings, landmarks and accessible names part of how your product gets summarised, so they deserve the same care as visual polish.

Firefox 161 ships next Tuesday

MDN lists Firefox 161 as the current beta with release on Nov 24, and so far the confirmed developer change is WebTransport support for concurrent stream properties, with the notes still being filled in. Add it to your cross-browser test matrix this week so any regressions in your components show up before users get it.
