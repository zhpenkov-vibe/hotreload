Update: Chrome 158 hits stable tomorrow and switches off XSLT

Chrome 158 is scheduled for stable on Nov 17, and Google's deprecation guide says XSLT, including XSLTProcessor and the XSLT processing instruction, stops working on stable from that release, with origin-trial and enterprise-policy escape hatches lasting until Chrome 176. If your docs site or token pipeline styles RSS feeds, sitemaps or XML exports with XSLT in the browser, move that transform to build time this week.

llama.cpp reaches 1.0 with a stable API

llama.cpp and ggml hit v1.0.0 on Nov 13, adopting semantic versioning, removing 35 deprecated functions and hardening llama-server against SSRF, CORS and DNS-rebinding issues. A stable local inference API makes it far safer to build offline tooling, like a docs assistant or lint helper for your component library, without chasing breaking changes.

Malicious stylelint-standard package flagged on npm

A package named stylelint-standard was flagged on Nov 13 as malware that can take over any machine that installs it, in a batch alongside casamare, ansi-sanitize and lineparse. Look-alike names for linting tools are aimed squarely at frontend teams, so check lockfiles for typo-squats of your stylelint and ESLint configs and pin exact package names in your templates.
