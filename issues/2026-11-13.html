Node.js patches seven high-severity flaws in the 22, 24 and 26 lines

The Nov 11 releases (22.23.5, 24.22.3 and 26.13.1) fix seven high-severity issues, including a TLS use-after-free that can leak server heap, even TLS private keys, into HTTPS response bodies, plus several HTTP/2 crashes and a TLS 1.2 renegotiation bypass of per-host client certificates. If your docs site, Storybook host or SSR app runs on Node, upgrade now, because end-of-life lines get no patch.

The beta post (Nov 9, updated Nov 10) details official ui-workflow and component-docs agent skills, a headless tools command with docs list and test run, fully type-safe CSF 4 stories and a package about 25% smaller, and it aims for a December release rather than the Nov 10 date in the earlier plan. Google launches the Gemini Decisions API at $0.10 per million input tokens

Announced Nov 11, the gemini-decision-1 model scores up to 1,000 yes/no, multiple-choice or rubric questions about one multimodal input in a single pass and returns confidence scores, with 150 to 250 ms end-to-end latency and no charge for output tokens, per Google. It suits routing, triage and classification, such as labelling component-request issues or screenshots, though the speed and cost figures are Google's own.

Use @starting-style with transition-behavior allow-discrete to animate a dialog in and out with no JavaScript.

dialog { opacity: 0;
  transition: opacity .2s,
    display .2s allow-discrete; }
dialog[open] { opacity: 1; }
@starting-style {
  dialog[open] { opacity: 0; } }
